# Dots OCR Local | نسخه اولیه

نرم‌افزار محلی OCR با موتور Dots OCR و پردازش CPU. رابط کاربری فارسی و راست‌چین است و فایل‌ها و خروجی‌ها روی همان کامپیوتر ذخیره می‌شوند.

## نکته مهم درباره سخت‌افزار
این نسخه برای CPU طراحی شده است. لینک پروژه در حال حاضر به نسخه جدید dots.mocr با ۳ میلیارد پارامتر اشاره می‌کند. روی Intel Core i7-7700 و RAM شانزده گیگابایت، اجرای CPU ممکن است بسیار کند باشد و حتی با کمبود حافظه روبه‌رو شود. کد از BF16 برای کاهش حافظه استفاده می‌کند، اما پشتیبانی و سرعت آن به CPU و PyTorch بستگی دارد.
- فقط یک سند در هر لحظه پردازش می‌شود.
- PDF در اندازه ۱۴۰ DPI و صفحه‌به‌صفحه پردازش می‌شود.
- تعداد صفحات هر PDF در نسخه اول حداکثر ۱۰ صفحه است.
- خروجی هر صفحه جداگانه ذخیره می‌شود.
- هیچ کدی CUDA یا GPU را فعال نمی‌کند.

**توجه:** CPU-only بودن به معنی سبک بودن مدل نیست. قبل از استفاده عملی، ابتدا یک تصویر کوچک و غیرمحرمانه را آزمایش کن.

## ساختار
- `backend/`: سرور FastAPI، موتور Dots و ذخیره‌سازی SQLite
- `frontend/`: رابط وب فارسی
- `vendor/dots.ocr/`: مخزن رسمی Dots OCR که هنگام نصب دریافت می‌شود
- `data/`: فایل‌های بارگذاری‌شده و نتایج OCR

## نصب روی Windows 10/11
1. Python 3.12 نسخه 64 بیتی را نصب کن.
2. فایل `setup_cpu.bat` را با اینترنت اجرا کن.
3. پس از اتمام نصب، وارد پوشه `vendor\dots.ocr` شو و دستور `python tools\download_model.py` را اجرا کن. این دستور وزن‌های dots.mocr را در `weights\DotsMOCR` می‌گذارد.
4. مسیر مدل را در فایل `.env` تنظیم کن. مقدار پیش‌فرض: `DOTS_MODEL_PATH=vendor/dots.ocr/weights/DotsMOCR`
5. `run.bat` را اجرا کن.
6. مرورگر را باز کن و برو به `http://127.0.0.1:8000`.

## دسترسی همکاران در شبکه داخلی
برای دسترسی LAN، در `run_lan.bat` سرور روی `0.0.0.0` اجرا می‌شود. در فایروال ویندوز فقط شبکه خصوصی شرکت را مجاز کن و آدرس IP کامپیوتر سرور را به همکاران بده؛ نمونه: `http://192.168.1.20:8000`

این نسخه هنوز احراز هویت ندارد؛ تا زمان اضافه شدن ورود کاربران، آن را روی اینترنت عمومی منتشر نکن.

## اجرای سریع بدون مدل
برای تست ظاهر و API بدون دانلود مدل، `run.bat` را اجرا کن. وضعیت مدل در صفحه به شکل «مدل پیدا نشد» نمایش داده می‌شود. آپلود و ثبت کار انجام می‌شود، اما OCR واقعی فقط پس از نصب مخزن و وزن‌های مدل فعال خواهد شد.

## محدودیت‌های نسخه اول
- فقط OCR و استخراج متن/ساختار صفحه
- پردازش PDF و تصویر
- صف تک‌پردازشی CPU
- ذخیره نتیجه در SQLite و فایل JSON/Markdown
- هنوز استخراج قطعی فیلدهای فاکتور و اتصال به دیتابیس خرید پیاده‌سازی نشده است؛ این مرحله بعد از ارزیابی OCR اضافه می‌شود.
